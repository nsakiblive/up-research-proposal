# UP research collaboration proposal

A standalone static landing page prepared for UP THERE, EVERYWHERE, introducing Nazmus Sakib's independent research practice. This project is separate from the portfolio repository.

## Source

The archive contains `index.html`, `styles.css`, `script.js`, `robots.txt`, `.nojekyll` and an `assets/` folder at its root. It uses plain HTML, CSS and JavaScript, with original images copied from the existing public portfolio. Portfolio case studies are linked as evidence; no portfolio files are modified.

## Publish on GitHub Pages

Create a new repository named `up-research-proposal` under `nsakiblive`. Unzip the package and upload its website files and `assets/` folder to the repository root. Enable Settings > Pages > Deploy from a branch > main > /(root).

The proposed Pages address will be `https://nsakiblive.github.io/up-research-proposal/` once GitHub confirms deployment. This URL is a planned address, not evidence of deployment.

## Features

- Responsive editorial layout, black / cream / yellow palette.
- Verified portfolio claims and project provenance.
- Keyboard-accessible image previews and responsive navigation.
- Email contact links and a copy-email button.
- No analytics, tracking, forms, data storage, or build dependencies.
- Search-engine noindex directive and robots exclusion for a focused outreach page. This is not access control.
